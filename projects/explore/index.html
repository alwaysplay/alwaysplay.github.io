A synchronized map, satellite/birds-eye view, and Street View — click, drag, or search, and all three panels stay locked to the same location.

How it works

  • Map, aerial (birds-eye), and Street View panels stay in sync as you pan, zoom, or drag any one of them
  • Search box with autocomplete to jump straight to a location
  • "My Location" button using browser geolocation
  • Toggle any panel on or off from the toolbar

Stack

Plain HTML/CSS/JS — no build step, no dependencies. Built on the Google Maps JavaScript API and Places API.
